# Evaluation and paper table index

This repository separates **reported paper values** from **new reference-model evaluations**:

- `results/*.csv` records values transcribed from the manuscript. Run `psr-render-table --table TABLE_ID` to format a CSV as Markdown. This command does not run inference.
- [`src/psr/evaluate.py`](../src/psr/evaluate.py) generates predictions from a reference checkpoint. [`src/psr/metrics.py`](../src/psr/metrics.py) computes reference accuracy, MSE, ROUGE-L F1, and BLEU where applicable. These scripts have not reproduced the manuscript's scores.

| `reasoning_results` | Five reasoning dimensions across training paths | [`reasoning_five_dimensions.csv`](../results/reasoning_five_dimensions.csv) | `psr-evaluate` on five-dimensional MCQA JSONL, with one checkpoint per path | Reference accuracy available; original evaluation set absent |

| `ood_results` | Weather and finance out-of-domain results | [`mtbench_ood.csv`](../results/mtbench_ood.csv) | `psr-evaluate` can score converted JSONL for our reference checkpoints | MTBench-specific conversion and baseline code absent |
| `perception_generalization` | TimeSeriesExam and CaTS-Bench | [`perception_generalization.csv`](../results/perception_generalization.csv) | Generic `psr-evaluate` can export predictions after conversion | Original F1/relative-accuracy protocol and benchmark adapters absent |
| `stage_saturation` | Does local convergence suffice? | [`stage_saturation.csv`](../results/stage_saturation.csv) | Train and evaluate each stage at prescribed data ratios | Exact subsampling manifests and original protocol absent |

Two useful appendix tables are also transcribed: `cate_num_comparison_detailed` in [`perception_detailed.csv`](../results/perception_detailed.csv) and `reasoning_data_scaling_detailed` in [`reasoning_data_scaling.csv`](../results/reasoning_data_scaling.csv). The latter's mixed-training and textualization branches, exact data subsampling, and benchmark protocol are not implemented in the reference pipeline.

## From a checkpoint to new scores

Prepare one JSONL evaluation file per benchmark using the [data contract](../code/README.md#data-contract). Give each example the paper's task family as `task` and keep the evaluation split separate from training. For example:

```bash
psr-evaluate \
  --config configs/pre_align.yaml \
  --checkpoint outputs/pre_align/perceive-solve-reason \
  --data data/eval/reasoning_dims.jsonl \
  --output outputs/eval/reasoning_dims_predictions.jsonl
```

This writes predictions and `outputs/eval/reasoning_dims_predictions.metrics.json`. The example path under `data/eval/` is a placeholder; no benchmark files are included. The `data/` directory is ignored by Git.

To view a reported table without running a model:

```bash
psr-render-table --table reasoning_results
psr-render-table --all --output outputs/reported_tables.md
```

Use different output names for different checkpoints. For the path comparisons, the reference trainer supports ordered subsets: `reason` only, `perceive → reason`, `solve → reason`, and `perceive → solve → reason`. A saved checkpoint records its stage history. The manuscript's numerical comparisons additionally require the original datasets, prompt templates, split manifests, and checkpoints, which are unavailable here.

## Figure provenance

The PNGs in [`assets/`](../assets/) are GitHub-friendly previews converted from the manuscript figures. They are **paper figures**, not plots newly generated by the reference implementation. The reasoning data-scale values have a companion CSV; the other plotted point data are not bundled.
